# task-3-Netflix_titles# Exploratory Data Analysis of Netflix Dataset

## Project Overview
This project focuses on performing Exploratory Data Analysis (EDA) on the Netflix Movies and TV Shows dataset.

## Objectives
- Understand dataset structure
- Analyze content distribution
- Identify trends and patterns
- Generate actionable insights

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab

## Analysis Performed
- Dataset Overview
- Statistical Summary
- Correlation Analysis
- Country-wise Analysis
- Rating Analysis
- Release Year Trend Analysis
- Movies vs TV Shows Comparison

## Key Insights
- Movies dominate Netflix content.
- Netflix experienced rapid growth after 2015.
- The United States contributes the highest number of titles.
- TV-MA is one of the most common content ratings.
- Netflix maintains a globally diverse content catalog.

## Conclusion
The EDA revealed important trends, content distribution patterns, and growth indicators that highlight Netflix's global expansion strategy.
